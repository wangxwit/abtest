# 交付校验记录

日期：2026-09-23 · 设计 v1.3 · [返回总览](./README.md)

本轮将一期 PostgreSQL 控制库收敛为 30 张表，同步权限、API、SDK、指标及产品文档。原型代码未改动，设计中的数据库和服务端能力尚未实现。

## 本轮更新

| 范围 | 结果 |
| --- | --- |
| 表数与边界 | 旧方案约 77 表归并为 30 张控制表；事件湖仓、持久资格及对象文件的边界单独说明 |
| 核心关系 | Namespace、成员、应用参数、层域、实验身份及桶账本保留；不以无约束万能表替代 |
| 冻结配置 | run 合并原一对一实验版本及分析计划；审批合并为 change_request；分析任务合并输入/结果元信息 |
| 细粒度授权 | 直接个人／机器绑定；真实业务归属继承；用户组、权限缓存与通用策略注册延后 |
| 发布安全 | 保留应用独立投影、签名、配置租约与上下文 TTL；先持久记录租约上界，再签发；排空后回收桶 |
| 基础设施 | 审计、Outbox、幂等各一张；保留作用域约束、消费幂等和原子写入 |
| 分桶兼容 | 本轮未改 hash 协议、字段、fixture 或验证脚本；原 v2 分配保持不变 |
| 阅读方式 | 30 表编号清单、旧表去向、职责树和核心事务步骤；其他文档引用同一模型 |

## 实际检查

| 检查 | 结果与边界 |
| --- | --- |
| 表清单 | 30 个编号表名与 30 份字段定义一致且无重复；模块计数合计一致；77 个旧表名均有去向 |
| Markdown | 36 份文档代码围栏闭合，236 处本地文件链接目标存在 |
| JSON | 28 个 JSON 代码块严格解析通过，拒绝重复键和非有限数；不等同于接口 Schema 验证 |
| Mermaid | 14 张图通过解析及浏览器 SVG 渲染；抽查数据库与权限关系图，文字可读 |
| 分桶向量 | Node 编码器复核 10 组 payload、SHA-256、64 位无符号值和桶号；拒绝孤立 Unicode surrogate 和旧协议标识 |
| 向量兼容性 | 与上次提交逐组比较：输入值、编码、摘要和桶号均未变化 |
| 统计口径 | 指标文档的 SQL 代码块与上次提交一致；本轮仅调整存储、任务及授权说明 |
| 交叉校对 | 核对 30 表的协议映射、已冻结历史、作用域、审批追加、输入冻结、租约签发和安全回收 |
| 变更范围 | 无原型源码、依赖或业务测试修改；git diff --check 通过 |

分桶样例复验命令：

```bash
node docs/服务端技术方案/verify-hash-vectors.mjs
```

脚本只验证字节编码和 hash 样例，不覆盖完整分流、资格服务、验签、跨服务上下文或埋点。Java／Go／移动端仍须实现并通过同一组向量。
