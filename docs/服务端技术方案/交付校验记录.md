分桶样例复验命令：

```bash
node docs/服务端技术方案/verify-hash-vectors.mjs
```

该脚本验证协议字节编码和 hash 样例，不实现完整层域求值、资格服务、验签、跨服务上下文或埋点链路。Java／Go／移动端还需实现并通过同一组向量。

SQL 是核心约束及计算设计片段，未执行建库迁移或仓库作业；HTTP 请求响应是待实现协议，未启动真实服务测试；性能目标为待压测预算。各专项文档中的并发、故障、数据质量和统计验收场景留作实施阶段的验收依据。本次修订设计材料、协议样例与文档入口，没有改动原型业务代码或用户实验配置。
