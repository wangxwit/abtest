# EXP Lab 平台使用手册

版本：依据当前 v23 前端原型编写；编写日期：2026-09-19。

本文面向应用负责人、实验创建者和平台管理者，说明当前界面能够完成的操作。产品边界见[产品设计](./01-产品设计.md)，运行机制见[技术方案](./02-技术方案.md)，团队约定见[平台管理与使用规范](./04-平台管理与使用规范.md)。

本手册不展开指标定义、采集、计算和结果分析。示例只用于说明配置流程，不构成上线或效果结论。

## 1. 开始前确认

当前平台是可运行的本地交互原型。应用、参数、层域、受众和实验保存在当前浏览器；接入配置、审核和分流验证用于演示设计流程。保存配置不会发布到真实业务服务。

- 统一使用同一个访问地址，例如 `http://localhost:5173`。
- `localhost:5173` 与 `127.0.0.1:5173` 属于不同来源，浏览器存储相互独立；切换地址后看到不同配置通常不是数据丢失。
- 换浏览器、浏览器用户配置或设备，也不会自动同步配置。清除站点数据可能删除本地配置和草稿。
- 无需真实生产凭证；应用接入状态保持“待验证”，运行观测显示未接入。
- 当前角色、负责人默认值和“演示审核人”不代表真实登录身份、权限或审批责任。

开发人员从项目根目录运行 `npm run dev` 后打开页面。若依赖尚未安装，先运行 `npm install`。运行环境要求及完整命令以项目 [README](../../README.md) 为准。

## 2. 找到正确入口

| 要做的事 | 界面入口 | 路由示例 |
| --- | --- | --- |
| 登记应用或服务 | 应用管理 | `#applications` |
| 管理某个应用的参数 | 应用管理 → 选择应用 → 参数 | `#applications/services/<应用标识>/parameters` |
| 配置服务接入方式 | 应用管理 → 选择应用 → 接入配置 | `#applications/services/<应用标识>/integration` |
| 查看域、层及流量占用 | 层域管理 → 层域配置 | `#traffic` |
| 验证用户分流路径 | 层域管理 → 分流验证 | `#traffic/validation` |
| 登记画像属性 | 受众管理 → 画像属性 | `#audiences/attributes` |
| 创建受众条件 | 受众管理 → 受众列表 | `#audiences` |
| 管理实验 | 实验管理 | `#experiments` |
| 创建实验 | 实验管理 → 创建实验 | `#experiments/new` |

应用详情包含“概览、参数、接入配置、运行观测、关联实验”五个页签。参数始终在所属应用下维护，没有独立的“全部参数”管理页面。

复制实际页面地址可保留对应应用、参数、域、层或受众版本定位。表中的尖括号内容需替换为真实标识；不要直接打开占位地址。

## 3. 第一次使用的推荐顺序

1. 在“应用管理”登记负责参数的应用或服务。
2. 记录该应用在各环境的接入方式。
3. 进入该应用的“参数”页签，注册参数并设置本应用标签。
4. 按业务需要准备参数层，再完成参数的首次归层。
5. 如果有用户资格限制，在“受众管理”准备画像属性和固定受众版本。
6. 从合适的参数层创建实验，配置实验流量、多个分组及参数值。
7. 完成检查后提交审核，再使用演示启动操作。
8. 在“分流验证”确认用户路径和实际命中的实验分组。

已经有合适的域、层、参数或受众时直接复用。创建实验本身不要求先创建一个新层或新域，也不要求按前端、后端、算法分别创建实验。

## 4. 登记应用与配置接入

### 4.1 登记应用

进入“应用管理”，点击“登记应用”，填写：

| 字段 | 填写方式 |
| --- | --- |
| 应用标识 | 2–64 个字符，以小写字母开头，可包含数字、连字符和下划线 |
| 应用名称 | 业务可识别的名称，例如“推荐召回服务” |
| 应用类型 | 前端应用、后端服务、策略服务、网关 / BFF |
| 负责人 | 实际负责维护该应用的人或团队 |
| 应用说明 | 描述业务能力及参数维护范围，选填 |

点击“登记应用”保存。应用类型用于表达服务职责，不决定实验属于哪个端。登记后会生成开发、测试、生产三个接入配置，初始方式为“应用直接决策”。

### 4.2 设置各环境的决策方式

进入应用详情的“接入配置”，先选择开发、测试或生产环境，再选择一种方式：

- “应用直接决策”：记录本应用获取配置并执行分流的接入设计。
- “委托网关 / BFF 决策”：选择已登记的其他网关 / BFF，记录由上游提供实验上下文的设计。

委托方式需要先登记网关 / BFF 类型的应用。不能委托自己，也不能形成循环；校验按对应环境执行。

点击“保存开发环境配置”“保存测试环境配置”或“保存生产环境配置”。保存只影响当前环境，切换前请先保存需要保留的修改。

参数所属服务不会因委托决策而改变。右侧“接入指引”中的代码是伪代码，不能直接作为 SDK 调用。当前页面不会生成凭证、验证网络或将应用标记为已连接。

### 4.3 处理历史参数待归属

应用目录仅在存在历史参数未指定服务时显示“历史参数待归属”。为相应参数选择服务，点击“确认归属并管理”，进入目标服务继续维护。

“待归属服务”表示参数缺少应用负责人边界；“待归层”表示参数尚未进入实验作用域。两种状态分别处理，确认服务归属不等于完成首次归层。

## 5. 注册参数、维护标签与首次归层

### 5.1 注册参数

进入“应用管理 → 目标应用 → 参数”，点击“注册参数”。所属应用已经固定，若入口选错，取消后从正确应用重新进入。

1. 填写参数 Key、显示名称和负责人；参数说明选填。
2. 选择 String、Number、Boolean、Object 或 Array 类型。
3. 按 JSON 格式填写默认值。字符串需使用双引号，例如 `"default"`；数字为 `20`；对象为 `{}`。
4. 可选择多个本应用业务标签。
5. 点击“注册参数”，确认详情出现“待归层”。

参数 Key 在整个工作空间唯一，当前要求 3–80 位、使用小写业务前缀与点号，例如界面提示的 `ranking.result_limit`。该名称只是填写示例，不保证当前目录中已经存在。

注册时不选层。默认值用于之后向实验分组加入参数时初始化，不会修改已有实验值，也不会自动下发到真实服务。当前参数定义没有原地编辑或删除入口，已明确的所属应用也不能直接迁移。

### 5.2 标签维护与批量分类

在参数详情的“业务标签”区域选择标签，点击“保存标签”。需要新标签时填写“创建当前应用标签”，点击“创建并选择”，再保存参数的标签绑定。

新标签在点击“创建并选择”时立即登记到当前应用；关闭参数注册窗口不会删除已创建的标签。参数与标签的关联仍以注册或“保存标签”为准。

在参数列表勾选多项，选择本应用标签，再点击“添加标签”或“移除标签”，可批量维护绑定。用“平铺列表 / 按标签”切换浏览方式；搜索、归层状态、域 / 参数层和标签可组合筛选。

同一应用内选择多个筛选标签时，满足任意一个即可显示。不同应用的同名标签相互独立；修改标签不会自动改变已保存实验的参数集合、分组取值或流量。

### 5.3 将待归层参数分配到层

选择待归层参数，点击“分配到层”：

1. 在“层域归属”中，为每个需要继承此参数的域选择一个归属层。
2. 选择带有子域的层后，继续补齐出现的下级归属；不同互斥分支需分别设置。
3. 检查“已选择域数 / 需要选择域数”，补齐所有要求的项。
4. 点击“保存归层”。保存成功后参数变为“已归层”，可用于对应层的新实验。

系统自动确定的路径不需要重复选择。如果没有合适的目标层，可先到“层域管理”创建待配置层，再回来归层。也可在新建层时选择待归层参数并一次完成层创建与首次分配。

首次归层是完整保存操作，不会先激活一半分支。待归层参数不会自动进入所有层，也不能先放进实验再补归属。

### 5.4 查看参数影响范围

参数详情的“在哪一层管理”按域展示当前归属，点击层名称可以进入对应层。下方实验引用展示使用该参数的实验及各组值，支持进入实验详情。

“转移受保护”说明存在未结束实验或子域继承等依赖，应先阅读原因。当前参数转移通过同域“新建层”完成，没有将已激活参数退回待归层的入口。

## 6. 管理域、层和流量

### 6.1 先理解树的含义

打开“层域管理 → 层域配置”。左侧树按“域 → 层 → 子域 → 子层”展开，右侧显示所选节点及面包屑。

- 域决定进入哪个流量分支，并继承父层参数范围。
- 同一重叠域内的层划分不同参数，可分别执行实验。
- 同一层的直接实验与子域共同占用该层的 10,000 个固定桶。
- 同一参数可出现在祖先层和继承子域中，但不能同时归属同域的两个并行层。

默认根域承担入口路由，界面会禁止在其中随意增加普通业务层。微服务所属关系不等于层：一个层可以承载多个应用的参数，一个应用的不同参数也可以属于不同业务层。

### 6.2 在父层中创建子域

选择有已激活参数的父层，点击“新建子域”。待配置空层不能继续创建子域。

1. 填写子域名称及“管理信息”。
2. 选择“重叠子域”或“非重叠子域”；受非重叠祖先限制时，界面会禁用不合法模式。
3. 可选择固定受众版本，也可保留“继承上级受众，不追加限制”。
4. 填写“占父层名义流量”，最小粒度为 0.01%，即 1 个桶。
5. 查看当前受众可用桶数、需避开的配置和拟分配桶段。
6. 检查继承参数列表，点击“创建子域”。

创建成功后，域内自动生成一个“初始参数层”，承接父层全部继承参数。此处不需要填写 A/B 子层名称，也不在创建域时拆分参数；应用或标签筛选仅帮助查看继承列表。

重叠子域可以后续按业务新增、拆分层。非重叠子域维持一个完整参数层，分支内实验互斥；它不会关闭祖先域的其他并行参数层。

### 6.3 在域内新增或拆分参数层

选择允许分层的域节点，点击“新建层”，填写层名称、层说明及管理信息，再选择参数。

- 暂时不选参数：点击“创建待配置层”。空层不能创建实验或子域，后续从应用参数入口分配参数。
- 选择待归层参数：补齐弹窗中的其他继承分支，点击“创建层并归层”。
- 从同域已有层选择可转移参数：查看“参数划分预览”，点击“创建层”。这会将参数分配到新层。

选参可搜索 Key、登记名称和应用，先选应用再使用它的私有标签；跨应用累计选择会保留。不可选参数旁的原因用于解释依赖保护，不应通过另建同义 Key 绕过。

转移已激活参数时，来源层须至少保留一个参数，且参数不能被未结束实验使用或被来源层子域继承。当前没有任意移动已有层、删除节点、修改已有域份额或运行中迁移入口。

### 6.4 看懂流量占用

层详情的“直接实验与子域共用流量桶”分别列出运行中实验、暂停 / 待审预留及直属子域占用。联合占用按桶坐标去重，不应直接将多行百分比相加。

申请流量时平台自动组合可用桶，不要求连续区间。桶段 `[100, 200)` 表示包含 100、不包含 200，共 100 个桶，即本层的 1%。

子域或实验展示的全局名义流量是沿祖先域比例折算的值。例如父域占全局 80%，当前申请父层 10%，折算为全局 8%。它不是受众实际合格人数，也不是实际曝光量。

“当前受众可用”还考虑完整受众条件。只有可证明互斥的固定资格条件才允许同父层复用桶坐标；条件可能重叠或无法证明互斥时，需要避开已有桶段。

### 6.5 管理信息与到期提醒

域、层详情均有“管理信息”。点击“编辑”或“补充信息”，填写负责人、使用期限，再点击“保存管理信息”。

- 负责人必填，最多 40 个字符；新建表单默认显示演示用户“陈思远”，保存前应改为实际责任人。
- 使用期限可选“长期”或“临时”；临时必须填写有效预计结束日期。
- 创建子域时，初始参数层复制本次管理信息；之后域与层可分别修改，不自动联动。
- “今日到期”与“已超期”按浏览器本地日期提示，允许记录已经过去的日期。
- 到期只提醒，不停用节点、不结束实验，也不自动回收流量。

旧节点可能显示“未设置”，可按实际情况补充。保存时发现其他页面修改过拓扑会拒绝过期写入并保留当前输入；不要将提示误认为已保存成功。

## 7. 维护画像属性与受众条件

### 7.1 登记画像属性

进入“受众管理 → 画像属性”，点击“登记画像属性”：填写属性 Key、显示名称、属性类型及“定义与统计口径”。

枚举属性需要填写允许取值，每行一个或用逗号分隔，区分大小写且不能重复。数值属性可填写单位、选择“仅允许非负整数”。应在统计口径中说明含义、统计窗口和缺失处理。

画像属性不填写来源应用，也不进入实验参数包。登记只是增加可选择的属性定义，不表示真实用户数据已经接入。已登记定义不能原地修改或删除；语义或类型改变时登记新 Key，再创建受众新版本。

### 7.2 创建 AND / OR 条件

进入“受众列表”，点击“新建受众”，填写名称、负责人和说明。

1. 在条件组中选择画像属性、运算符和条件值。
2. 使用 AND 表示组内全部满足，使用 OR 表示组内任一满足。
3. 需要括号关系时新增子条件组；支持最多 3 层分组、30 条规则。
4. 查看右侧“整体条件”，确认括号及组合逻辑符合目标人群。
5. 如果不追加限制，明确勾选“所有符合上级条件的用户”。

“画像资格预览”可手动填写一个临时画像，点击“验证当前画像”，只检查是否符合有效条件。留空表示缺属性，可能得到“资格未知”；此预览不保存用户，也不估算实际人数。

### 7.3 读取创建前检查

“创建前检查”随条件自动更新，保存前还会读取最新配置再次检查。

| 检查结果 | 如何处理 |
| --- | --- |
| 条件未填完整或自身矛盾 | 点击问题定位并修正，不能保存无效条件 |
| 与其他受众可能重叠 | 中央受众登记允许重叠；继续检查该受众的使用位置 |
| 与祖先条件交集为空 | 在域或实验内不能保存使用，需修改条件或选择合适作用域 |
| 当前层可用桶总量不足 | 内联创建不能保存并选用，取消后调整父表单流量或受众条件 |
| 无法证明互斥 | 保守使用独立桶，不能按互斥关系复用已有坐标 |

从域或实验旁的“新建受众”进入时，检查包含祖先条件及当前申请流量，成功后点击“保存并选用”会自动回填固定版本。单独保存受众不会预占流量。

### 7.4 创建新版本及查看引用

已有受众详情点击“创建新版本”，修改后“保存新版本”。旧域和实验继续引用旧版本，不会被新版本自动替换；当前原型没有批量替换已有引用入口。

受众详情的“查看引用实验”进入实验列表，并按当前固定版本筛选，包含直接引用及通过祖先域继承的实验。可继续叠加名称搜索、状态、涉及服务和“只看我负责的”。

该地址形如 `#experiments?audience=<受众版本 ID>`，可刷新保留受众条件。“清除受众筛选”只清除受众限制，其他条件可能仍生效；空列表可使用“清除筛选”恢复查看。

画像属性详情按直接使用该属性的受众版本提供引用实验列表入口。域引用点击后进入对应域及条件说明。引用数量表示配置关系，不代表真实用户已入组。

## 8. 创建多分组实验

### 8.1 进入四区工作区

可从实验管理点击“创建实验”，从层详情点击“创建实验”，或从已有实验详情点击“复制为新实验”。从层进入会带入当前域与层；复制会保留参数值及固定受众资格，生成新的分组 ID，不复用原实验桶。

工作区分为“实验目标、范围与流量、分组与参数、检查与提交”，可自由切换，不要求先填完当前区。各区显示待处理问题数。

“实验目标”填写实验名称、唯一标识、描述和可选假设。当前兼容表单仍要求选择核心指标并满足既有护栏字段校验，用于走通原型流程；本手册不定义或展开指标方案。

### 8.2 选择范围与流量

在“范围与流量”依次选择实验域、参数层、受众版本及本域内实验流量。默认根域仅路由，空层需先分配参数；非重叠域的完整参数层固定。

检查完整分配路径及“继承条件 / 追加条件”。实验可以缩小祖先受众范围，不能通过选择全体用户绕过祖先限制。域名中的“全参数”只指该分支继承的范围。

查看拟分配桶数和全局名义比例，必要时展开需避开的配置与桶段。草稿不预占流量，因此此时可用不代表稍后一定可提交。

### 8.3 按应用批量加入参数

进入“分组与参数”，展开“按应用与标签选择参数”：

1. 选择应用，按 Key、参数名、服务名称搜索，也可按本应用标签筛选。
2. 勾选参数或点击“选择当前可加入项”。
3. 需要跨应用联动时切换应用继续选择，已选待加入项会保留。
4. 点击“批量加入”，把参数补入所有分组；已有值保留，新项使用登记默认值。

参数必须已明确服务归属、已归层，并在当前层允许范围内。越层、待归层、待归属服务或已加入项会显示不可加入原因。若跨应用参数分散在不同层，需先选择承接完整组合的合法层域，不能跨层强行加入。

“初始化与配置说明”中的“用当前层参数初始化所有组”会重写各组配置为该层全部参数初值；仅在确实需要重置时使用，随后可点击“撤销初始化”。

### 8.4 配置 2–20 个实验分组

每个实验保留唯一对照组，至少 2 个、最多 20 个分组。点击分组后展开“分组设置”修改名称、组内流量及角色。

- “新增实验组”复制对照组参数，初始流量为 0，需要再分配。
- “复制此组”复制当前组参数，生成新分组 ID，也从 0 流量开始。
- “设为对照组”将当前组设为唯一对照，原对照变为实验组。
- 删除只能作用于非对照组，且至少保留两个组。需要删对照组时，先将其他组设为对照。
- “均分流量”显式调整所有组的比例；新增或删除不会自动重分其他组。

所有分组的流量须为正数，合计 100%。分组比例以本实验流量为分母：实验申请域内 20%，某组权重 50%，该组名义占本域 10%。各分组必须使用同一顶层参数 Key 集合。

## 9. 编辑上百行参数与策略 JSON

### 9.1 源码工作台

选择分组后，在“源码编辑”修改完整 JSON。顶层必须为对象；顶层 Key 对应已选实验参数，参数值可以是普通值或嵌套对象、数组。对象内路径不等于独立注册参数，仍受该顶层参数的服务归属与层边界约束。

使用“搜索 / 替换”“折叠”“展开”“格式化”以及撤销 / 重做处理长配置。点击“专注编辑”扩大编辑区域，在专注模式顶部可切换分组，再点击“退出专注”返回。

目录只读展示对象、数组与内部路径，可搜索字段、路径、值和登记名称，也可按应用及其标签筛选。点击目录项定位源码；目录筛选不删除源码内容，也不增删实验参数。

各组在当前编辑器会话内分别保留光标、折叠、滚动和撤销记录。刷新后保留草稿原文，但不恢复这些临时编辑器状态。目录最多显示 5,000 个节点，完整文本仍可搜索并参与校验。

### 9.2 修正 JSON 问题

点击状态栏的“JSON 问题”展开问题列表，再点击问题跳转到行、列。内容必须是严格 JSON，不支持注释、尾逗号、重复属性或非有限数字；最大嵌套深度为 32 层。

“格式化”仅处理通过校验的内容。编辑未完成或格式错误时，原文仍可随草稿保存；“已保存到本机”表示文本已保存，不表示配置可提交。

删除某个实验参数需要在所有分组源码中一致删除对应顶层 Key，不能仅从目录隐藏它。单组增加或删除顶层 Key 会触发组间参数集合检查。

### 9.3 比较分组差异

切换“分组差异”，选择一个实际分组作为“比较基准”，查看它与当前分组的新增、删除和修改路径及前后值。

差异忽略缩进和对象字段顺序；数组按整体比较，元素重排也计为修改。任一组 JSON 无效时需先修正才能比较。“定位源码”用于返回当前组对应位置。

差异面板不应用补丁、不自动合并，也不建立组间继承关系。当前没有参数表格、可编辑 JSON 树、固定基线 / 覆盖编辑、字段 schema 或 CSV 导入入口。

## 10. 保存草稿、处理冲突与提交

### 10.1 自动保存与继续编辑

修改后约 400 毫秒自动保存，也可点击“保存草稿”。首次保存后地址变为 `#experiments/drafts/<草稿 ID>`；工作区会保存表单原文、当前分区和所选分组。

确认顶部显示“已保存到本机”后离开。回到实验列表，在“编辑中的草稿”继续；刷新同一草稿地址也可恢复。草稿只在当前浏览器来源可见，不预留流量。

### 10.2 保存失败或版本冲突

发现同一草稿被其他页面更新、已经在其他页面提交，或本地存储不可用时，自动保存会停止，当前输入保留。先处理提示，再继续修改。

| 可见操作 | 作用与注意事项 |
| --- | --- |
| 另存当前草稿 | 将当前输入保存为另一份本地草稿；存储仍不可用时也可能失败 |
| 导出当前内容 | 从保存错误提示中导出当前表单及编辑状态，先保留一份文件 |
| 加载最新版本 | 用本地存储中的最新草稿替换当前工作区，先保存需要保留的当前输入 |
| 保存草稿 | 修复存储问题后可重试；版本冲突不会被当作无条件覆盖 |

不能读取的草稿不会被自动改成空白草稿。已提交的草稿会显示“这份草稿已提交”及对应实验入口；避免通过反复点击创建重复实验。

### 10.3 检查并提交审核

点击“检查并提交”，逐项检查实验路径、有效受众、流量、参数及各分组配置。点击问题可定位到相应配置区、分组和参数 Key，修正后再检查。

“配置检查通过”后点击“提交审核”。提交时重新检查最新层域、参数、受众和流量，成功后生成正式实验并预留桶，状态为“待审核”。若流量已被其他配置占用，会保留草稿并提示重新调整。

## 11. 查看实验与演示状态操作

在实验管理中使用搜索、状态、涉及服务及受众筛选定位实验，进入详情的“实验配置”查看完整分配路径、受众条件、桶段和分组配置。“操作日志”记录原型内的状态操作。

| 当前状态 | 页面操作 | 桶与执行变化 |
| --- | --- | --- |
| 待审核 | 演示审核通过并启动 | 再次校验后变为运行中，模拟器可以执行该实验 |
| 待审核 | 退回草稿 | 释放预留桶，成为正式实验记录中的草稿状态 |
| 正式实验草稿 | 提交审核 | 重新校验并申请桶 |
| 运行中 | 暂停实验 | 保留原桶，模拟器不执行实验参数 |
| 已暂停 | 恢复实验 | 校验通过后恢复执行 |
| 运行中 / 已暂停 | 结束实验 | 页面要求确认，结束后不再执行且不支持恢复 |

“退回草稿”产生的正式实验状态，与列表上方“编辑中的草稿”不同。正式实验详情目前没有原地修改配置入口；需要改配置时使用“复制为新实验”，再走新草稿流程。

这些按钮只演示本地状态变化，未接入真实审核角色、服务端审批或生产配置发布。复制已结束实验也会创建新的实验身份，不会恢复旧实验。

## 12. 验证完整分流路径

进入“层域管理 → 分流验证”，或从某个域 / 层详情点击“验证分流”。后者只增加关注节点，实际模拟仍从默认域开始，保留全部并行分支。

1. 输入 1–128 位模拟 `user_id`。
2. 对第一次使用的 ID，填写需要的入组前画像；留空表示缺少属性。
3. 点击“固定画像并模拟”；已有快照时按钮为“使用固定画像模拟”。
4. 查看完整分配路径中的桶位、受众判定、实验分组及跳过原因。
5. 展开“查看合并后的参数覆盖”，核对运行中且实际命中的实验所提供的显式参数。

同一 ID 第一次保存的画像固定为只读，之后新增属性也不能补填。验证另一种画像时请换一个新的模拟 ID。不要把临时资格预览与这里持久保存的首次画像混为一谈。

“已到达”关注域或层不等于已经命中实验。未到达时，可点击“查看阻断位置配置”检查祖先桶外、受众未匹配或资格未知等原因；空层会跳过。

缺少属性或受众不匹配不会改投其他桶补量；其他并行层继续各自执行。暂停和待审实验保留桶坐标，但不产生运行参数覆盖。

输入或配置变更后，旧结果会提示“请重新验证”。在层域配置与分流验证间往返可保留当前会话输入和结果；刷新或离开一级导航不承诺恢复模拟结果，但已保存首次画像仍保留。

## 13. 导出范围与常见排错

当前“实验管理 → 导出清单”下载实验清单 CSV，不是完整工作空间备份。参数编辑器右上方下载图标导出当前组 JSON 源码原文，格式错误文本也原样导出。草稿整份“导出当前内容”仅在保存错误提示区域提供。

当前没有整站配置备份 / 恢复、草稿文件导入或跨设备同步按钮。保留导出文件并不意味着可以一键恢复工作空间；不要为排错直接清空浏览器站点数据。

| 遇到的问题 | 建议检查 |
| --- | --- |
| 打开后配置像是变了 | 核对主机名、端口、浏览器及用户配置，特别是 localhost 与 127.0.0.1 |
| 新参数在实验中不可选 | 查看是否已明确服务、已完成全部首次归层，且在当前层范围内 |
| 看不到其他应用的同名标签 | 标签属于当前应用，切换应用后重新选择其标签 |
| 新建层 / 子域按钮不可用 | 查看根域路由限制、非重叠约束、空层状态和页面原因提示 |
| 流量显示还有剩余却不能提交 | 检查当前父层、直接实验与子域联合占用、有效受众及最新配置变化 |
| 一组 JSON 有效但实验仍有错误 | 检查其他组、顶层 Key 集合、登记类型、当前层范围和组内流量合计 |
| 受众新版本没有改变旧实验 | 引用按固定版本保存，新版本不会自动替换旧引用 |
| 引用实验列表为空 | 核对受众版本及其他筛选，可清除筛选后重新选择 |
| 模拟用户无法修改画像 | 首次资格已固定，改用新的 user_id 验证另一种画像 |
| 模拟没有命中预期实验 | 查看状态是否运行中、祖先路径、当前桶位及完整受众条件 |
| 提示草稿或拓扑版本冲突 | 保留当前输入，先导出可导出的内容，再按页面操作加载或另存 |
| 接入状态始终待验证 | 当前只记录设计配置，真实 SDK、连接校验和运行观测尚未接入 |
