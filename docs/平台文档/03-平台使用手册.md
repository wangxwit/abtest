# EXP Lab 平台使用手册

设计 v1.2 · 2026-09-23｜操作基线：v23 前端原型

本文只把已实现界面写成操作步骤。Namespace、授权和生产发布另列为规划，不代表当前存在对应按钮。规则见[产品设计](./01-产品设计.md)。

## 1. 开始使用

从仓库根目录运行 `npm install`、`npm run dev`，打开命令输出的地址；详细要求见[仓库 README](../../README.md)。

- 固定使用同一地址、浏览器与用户配置。localhost 和 127.0.0.1 的数据不共享。
- 配置与草稿保存在浏览器；没有跨设备同步或整站备份／恢复，清站点数据可能丢失内容。
- 接入配置、审核和运行状态用于演示，不会发布到真实服务；演示指标不能用于业务判断。
- 负责人、演示用户和团队页不提供真实身份或授权。

| 任务 | 当前入口 | 路由 |
| --- | --- | --- |
| 应用目录 | 应用管理 | `#applications` |
| 应用参数 | 应用管理 → 应用 → 参数 | `#applications/services/<id>/parameters` |
| 接入配置 | 应用管理 → 应用 → 接入配置 | `#applications/services/<id>/integration` |
| 层域树 | 层域管理 → 层域配置 | `#traffic` |
| 模拟分流 | 层域管理 → 分流验证 | `#traffic/validation` |
| 画像定义 | 受众管理 → 画像属性 | `#audiences/attributes` |
| 受众版本 | 受众管理 → 受众列表 | `#audiences` |
| 实验与草稿 | 实验管理 | `#experiments` |
| 新实验 | 实验管理 → 创建实验 | `#experiments/new` |

推荐顺序：登记应用 → 注册参数 → 完整归层 → 准备受众（需要时）→ 创建实验 → 演示启动 → 分流验证。已有资源直接复用，不必每次新建域或层。

## 2. 应用与参数

### 登记应用和接入意图

1. “应用管理 → 登记应用”，填写标识、名称、类型、负责人和说明。
2. 应用标识为 2–64 字符，小写字母开头，可含数字、连字符、下划线。
3. 保存后进入详情：概览、参数、接入配置、运行观测、关联实验。
4. 在“接入配置”选择开发／测试／生产，设置“应用直接决策”或“委托网关 / BFF 决策”，保存当前环境。

委托对象须已登记为网关／BFF，不能委托自己或形成环。三个环境目前仅是接入意图，未提供三套独立实验拓扑。页面指引是伪代码，不生成凭证或验证连接，状态保持“待验证”。

存在历史未归属参数时，目录显示“历史参数待归属”；选择应用并“确认归属并管理”。这只确认应用，不完成参数归层。

### 注册与标签

1. “应用 → 参数 → 注册参数”，当前应用已固定。
2. 填写 Key、名称、类型、默认值、负责人和可选说明；Key 当前要求 3–80 位，示例 `ranking.result_limit`。
3. 默认值按 JSON 填写，如 `"default"`、`20`、`false`、`{}`、`[]`。
4. 可选择多个本应用标签，保存后参数处于“待归层”。

当前 Key 在本地工作区唯一；生产设计为 Namespace 内唯一。默认值仅用于加入实验时初始化。当前没有参数定义原地编辑／删除或已归属应用迁移入口。

| 标签操作 | 行为 |
| --- | --- |
| 创建当前应用标签 → 创建并选择 | 立即登记标签；关闭参数窗口不会删除已创建标签 |
| 参数详情 → 保存标签 | 保存当前参数的标签绑定 |
| 参数列表勾选 → 添加／移除标签 | 批量维护本应用参数分类 |
| 平铺列表／按标签、搜索及筛选 | 只改变显示；同应用多标签为任一匹配 |

标签不跨应用共享，也不会改变已保存实验的参数集合。

### 完成首次归层

选择待归层参数，点击“分配到层”：

1. 为每个需要继承该参数的域选择一个层；单一路径可自动选择。
2. 选中层有子域时，继续补齐所有下级归属。
3. 核对“已选择域数 / 需要选择域数”，点击“保存归层”。

必须整体完成，不能激活一半分支。没有合适层时，可先建待配置层；也可在新建层时选择待归层参数并补齐归属。详情的“在哪一层管理”和引用实验可检查影响范围。

## 3. 层域与流量

```text
默认根域 → 唯一根路由层 → 子域
                           └ 参数层 → 直接实验或子域
```

根域不允许随意增加普通业务层；根路由层不直接建实验。同一域参数完整且唯一归层，子域完整继承父层范围。非重叠域只隔离当前分支，不关闭祖先域的其他并行层。

| 任务 | 操作 |
| --- | --- |
| 创建子域 | 选有参数的父层 → 新建子域 → 名称、管理信息、模式、受众与流量 → 检查继承参数 → 创建子域 |
| 创建空层 | 在允许分层的域 → 新建层 → 填信息、不选参数 → 创建待配置层 |
| 新参数归层 | 新建层中选待归层参数，补齐其他分支 → 创建层并归层 |
| 拆分已有层 | 新建层中选择允许转移的参数 → 检查参数划分预览 → 创建层 |

子域创建时只生成一个“初始参数层”，不要求填写 A/B 子层。空层不能建实验或子域。转移须无未结束实验、无子域继承依赖，原非空层至少留一个参数；当前无任意移动、删除节点、修改既有域份额或运行中迁移入口。

每层固定 10,000 桶，自动组合空闲碎片，不搬旧桶。`[100,200)` 为 100 桶，即本层 1%。实验和直属子域共用桶；按坐标并集计算占用，不能直接累加展示百分比或多个并行层。

“全局名义流量”是原型根域路径比例乘积；生产对应当前 Namespace 的当前环境，不是企业全部用户。父域 80%、实验占父层 10%，名义为 8%，不等于实际合格或曝光人数。固定资格可证明互斥才允许复用相交桶。

“管理信息 → 编辑／补充信息”支持负责人、长期／临时及结束日期。负责人必填且最多 40 字；临时资源需有效日期。初始层仅在创建时复制域信息，之后独立维护；到期只提醒，不停实验或收桶。

## 4. 画像与受众

1. “画像属性 → 登记画像属性”，填写 Key、名称、类型、取值及“定义与统计口径”；不填来源应用。
2. “受众列表 → 新建受众”，填写名称、负责人和说明。
3. 组合 AND／OR 条件，最多 3 层组、30 条规则；不追加限制时明确选择“所有符合上级条件的用户”。
4. 检查整体条件和创建前检查，保存固定版本。

画像登记只是字段定义，不查询真实用户；已登记定义无原地修改／删除入口。语义变化使用新 Key。受众详情的“创建新版本”不替换旧引用。

| 检查提示 | 处理 |
| --- | --- |
| 条件不完整／自身矛盾 | 定位修正后再保存 |
| 普通受众可能重叠 | 目录允许；实际分配时再检查桶 |
| 与祖先条件交集为空 | 调整条件或目标分支 |
| 当前层可用桶不足 | 调整父表单流量或受众 |
| 无法证明互斥 | 使用独立桶，不复用相交坐标 |

域／实验旁快捷“新建受众”会结合祖先条件和申请流量检查，“保存并选用”回填版本；单独保存受众不占桶。“画像资格预览”只判断手填样例，不保存用户或估算人数。

“查看引用实验”按固定版本进入实验列表，包含祖先继承引用；可叠加其他筛选。清除受众筛选不一定清除其他条件。画像属性详情按引用受众版本提供同类入口，引用数不是入组人数。

## 5. 创建多分组实验

从“创建实验”、层详情“创建实验”或“复制为新实验”进入四区工作区：

| 配置区 | 操作要点 |
| --- | --- |
| 实验目标 | 名称、唯一标识、描述、假设；按当前表单填写核心指标和护栏字段 |
| 范围与流量 | 普通参数层、固定受众版本、实验流量；检查祖先条件与拟分配桶 |
| 分组与参数 | 批量选参、2–20 组、唯一对照、权重及完整 JSON |
| 检查与提交 | 定位并修复全部问题，按最新配置重新检查后提交审核 |

无需选择前端／后端／策略实验类型；涉及应用由参数推导。复制生成新分组 ID，不复用旧桶或运行状态。

在“按应用与标签选择参数”中搜索、选择应用及私有标签、跨应用累计勾选，再“批量加入”。已有值保留，新 Key 使用默认值；待归层、越层或待归属应用的参数不能加入。跨应用参数必须属于同一个合法参数层。

| 分组操作 | 行为 |
| --- | --- |
| 新增实验组 | 复制对照组参数，新组初始 0 流量 |
| 复制此组 | 复制当前参数，生成新 ID，初始 0 流量 |
| 设为对照组 | 原对照变为实验组，始终唯一对照 |
| 删除 | 只能删非对照，至少保留两组 |
| 均分流量 | 显式调整全部组；增删组不会自动重分其他组 |

提交时各组权重须为正且合计 100%，顶层 Key 集合一致。“用当前层参数初始化所有组”会重写配置，只有确需重置时使用，可“撤销初始化”。

## 6. JSON 工作台与草稿

| 能力 | 当前行为 |
| --- | --- |
| 源码编辑 | 每组完整 JSON；搜索／替换、折叠、格式化、撤销／重做 |
| 专注编辑 | 扩大编辑区，可切组，退出后返回工作区 |
| 只读目录 | 搜索路径／字段／值／登记名，按应用与标签筛选，点击定位源码 |
| JSON 问题 | 定位行列；拒绝注释、尾逗号、重复 Key、非有限数，最大深度 32 |
| 分组差异 | 选择实际比较组，查看新增／删除／修改；忽略对象顺序，数组整体比较 |
| 原文导出 | 下载当前组源码；错误文本也原样保留 |

目录最多展示 5,000 节点，完整文本仍参与检查。内部路径不是独立参数，不能分给不同层。删除顶层参数须在所有组一致修改；目录筛选不删除内容。差异只读，无补丁合并、固定基线继承或可编辑树。

修改约 400 毫秒后自动保存，也可“保存草稿”；确认“已保存到本机”再离开。地址为 `#experiments/drafts/<id>`，可刷新或从“编辑中的草稿”恢复。每组光标、折叠和撤销历史仅本次会话保留，刷新只恢复草稿原文。

| 冲突／失败操作 | 用途 |
| --- | --- |
| 另存当前草稿 | 将当前输入保存为另一份草稿 |
| 导出当前内容 | 在保存错误区导出整份当前输入 |
| 加载最新版本 | 替换当前工作区前，先保留需要的输入 |
| 保存草稿 | 修复存储问题后重试，不强行覆盖冲突 |

草稿不占桶、允许错误原文；“已保存”不等于可提交。检查通过后“提交审核”，成功生成待审核实验并预留桶；最新桶不足时保留草稿。已提交草稿提供对应实验入口。

## 7. 演示状态与分流验证

| 状态／操作 | 原型效果 |
| --- | --- |
| 待审核 → 演示审核通过并启动 | 校验后运行，模拟器可执行 |
| 待审核 → 退回草稿 | 释放预留，成为正式实验记录的草稿状态 |
| 正式实验草稿 → 提交审核 | 重新校验与申请桶 |
| 运行中 → 暂停 | 保留桶，不输出实验参数 |
| 暂停 → 恢复 | 校验后恢复执行 |
| 运行／暂停 → 结束 | 页面确认后结束，不支持恢复 |

正式实验草稿与“编辑中的草稿”不同。详情没有原地改配置入口，需“复制为新实验”。这些操作不是生产审批、发布或桶回收协议。

“层域管理 → 分流验证”始终从根开始；从域／层进入只设置关注位置，不截断其他并行分支：

1. 输入 1–128 位模拟 `user_id`，首次使用时填写入组前画像。
2. 点击“固定画像并模拟”或“使用固定画像模拟”。
3. 查看祖先路径、桶位、资格、分组和跳过原因。
4. 展开“查看合并后的参数覆盖”，核对命中且运行中的配置。

首次画像之后只读，缺失及新增字段都不能补填，其他画像请换新 ID。未命中不会换桶补量；关注节点“已到达”不代表入组。配置变化后需重新验证；首次画像可持久保存，模拟结果不承诺刷新恢复。

## 8. 导出与排错

“导出清单”只是实验 CSV；当前组 JSON 和错误区草稿导出也不是整站备份。没有文件导入或一键恢复入口。

| 问题 | 优先检查 |
| --- | --- |
| 配置像被清空 | 地址、端口、浏览器来源是否改变 |
| 参数不可选 | 应用归属、完整归层、目标层范围 |
| 有剩余流量仍失败 | 当前层、完整受众、直接实验与子域联合占用 |
| 单组 JSON 正确仍报错 | 其他组、Key 集、类型与权重合计 |
| 模拟未命中 | 运行状态、祖先路径、桶位与固定资格 |
| 标签／引用列表不符预期 | 当前应用、固定受众版本及叠加筛选 |
| 版本冲突 | 保留输入，再另存／导出或加载最新版本 |
| 接入始终待验证 | 当前尚无真实 SDK 或运行观测 |

## 9. 生产规划：当前不可操作

Namespace 将直接承接旧项目；账号可加入多个 Namespace，成员仅准入。资源权限由角色动作、范围及可选环境约束决定，owner／标签不会自动赋权。Namespace 目录隔离、各环境独立拓扑、后端 API、真实审批发布及结果权限均待实现，见[Namespace 与权限设计](../服务端技术方案/05-Namespace与权限设计.md)。

普通参数表格、固定基线覆盖、可编辑 JSON 树、字段 Schema 和批量导入也未实现，见[配置优化方案](../多分组与批量参数配置方案.md)。本次手册基于源码与已有流程整理，未重新执行浏览器验收；记录见 [VERIFICATION](../VERIFICATION.md)。
