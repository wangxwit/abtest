## 统一口径

```text
单企业平台：全局账号、用户组、角色模板
└ Namespace：完整实验资源与授权作用域
  ├ 应用 → 参数、应用私有标签
  ├ 画像属性、受众、指标目录
  └ 环境 → 根域 → 唯一根路由层 → 子域
                                      └ 参数层 → 实验或子域（递归）
```

- Namespace 直接承接旧项目，不额外叠加 project／space，也不等同团队；平台不设计租户实体。
- Namespace 隔离资源、配置、权限和分桶空间；业务用户仍可参与多个 Namespace，流量不自动互斥，效果也不独立。
- 应用拥有参数；域切流量，层分参数；实验固定参数集合，分组配置参数值；受众定义资格。
- 全局账号可加入多个 Namespace。成员资格只授予准入，资源操作按角色动作、资源范围及可选环境限制授权。
