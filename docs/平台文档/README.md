# EXP Lab 平台文档

文档版本：1.0  
整理日期：2026-09-19  
实现基线：当前仓库源码，README 标识为 v23 前端交互原型

本套文档覆盖企业 AB 实验平台的产品设计、技术方案、实际操作与管理规范。内容围绕应用和参数、递归层域、受众条件、实验分组与配置管理展开，暂不包含指标体系、统计计算和效果分析设计。

后续生产建设的详细设计见独立的[服务端技术方案](../服务端技术方案/README.md)，补齐数据库、管理及运行接口、SDK、指标生产和统计分析。本目录继续作为当前原型的产品与使用说明入口；新服务端契约以该专项文档为准。

## 共同约定

- **原型已实现**：在当前前端代码中具备交互、本地校验或本地持久化能力，不代表已接通生产服务。
- **生产方案或规划**：面向后续建设的设计建议，当前没有对应的真实后端、SDK 或发布保障。
- **组织执行**：需要团队落实的责任和流程，不表示当前界面已提供权限或审批控制。
- **示例**：用于说明关系的拓扑、参数或流量比例，不是现有配置迁移指令，也不是强制模板。

应用拥有参数，标签在应用内分类；域划分流量，层划分参数；实验固定参数集合，分组配置参数值；受众规定用户资格。服务边界与层域边界分别管理，不以服务数量决定层数。

所有文档均以当前源码核对为基础。原型支持本地模拟，参数默认值只用于编辑初值，接入配置仍待真实验证。本文档编写没有重新执行产品验收，也没有修改业务代码、用户配置或运行状态。

## 文档与历史材料

本目录是本次按最新功能汇总的阅读入口。仓库原有 PRD、架构文档、专项方案及验收记录保留为历史资料；其中的旧流程、规划项和版本结论须结合日期阅读，不应直接作为当前操作手册。

后续修改功能时，应同步维护对应文档：规则与模块变化更新产品设计，数据和运行协议变化更新技术方案，入口与步骤变化更新使用手册，职责与管理要求变化更新规范。历史验收记录不能代替新版本验证。

## 模型参考

递归层域的基础来源为 [Tang 等 2010 年论文 Overlapping Experiment Infrastructure](https://research.google/pubs/overlapping-experiment-infrastructure-more-better-faster-experimentation/)。10,000 桶、根域结构限制、应用标签和本文生产工程方案是本平台的设计选择。具体来源及实现依据见各文档对应章节。
