## 当时设计

| 入口 | 行为 |
| --- | --- |
| `#applications` | 应用目录；必要时显示旧参数认领区 |
| `#applications/services/<id>/<tab?>` | 应用详情及可刷新页签 |
| `#applications/services/<id>/parameters/<key?>` | 仅当前应用参数 |
| 旧全局参数列表 | 返回应用目录 |
| 旧参数深链 | 定位真实所属应用；未知项显示空态 |

注册固定当前应用，搜索、批量操作和参数详情都校验归属。切换应用不保留可越界写入的勾选；认领和导航不改变已有实验值与分桶。

v9 当时仍使用共享标签，该部分不再适用。
