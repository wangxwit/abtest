# 应用内参数维护设计

v9 · 2026-09-12。用户已明确要求取消“全部参数”页面，参数在所属应用／服务下维护。本文件记录已授权范围，不增加审批步骤。

## 范围

- 一级入口仍为应用管理，默认显示应用目录。具体应用的五个页签为概览、参数、接入配置、运行观测、关联实验。
- 参数页签承载该应用参数的注册、搜索、标签／层筛选、单项／批量标签、定义、层域归属、实验引用与版本值。
- 注册参数时 serviceId 固定为当前应用，不能切换服务或行内登记其他应用。新应用从目录登记。
- 标签保持项目共享；跨服务按标签选参仅在创建实验 ParameterPicker 中完成，不另建全局参数维护页。
- 历史未归属参数从应用目录内的认领区补齐；只有存在这类参数时显示认领区。

## 路由与隔离

| 路由 | 行为 |
| --- | --- |
| `#applications` | 应用目录 |
| `#applications/services/<id>/<tab?>` | 应用详情，可刷新恢复页签 |
| `#applications/services/<id>/parameters/<key?>` | 当前应用参数列表或详情 |
| 旧全局参数列表 | 返回应用目录 |
| 旧参数 Key 深链 | 按服务绑定定位实际所属应用 |
| `#applications/unassigned/<key>` | 未归属／未知 Key 在目录内反馈，无全局维护列表 |

参数目录先限定当前服务，再执行其他筛选。详情 Key、批量勾选和注册 serviceId 均须在当前服务范围；服务切换不能保留越界修改对象。未知 Key 或服务与 Key 不匹配不能回退展示另一个可编辑参数。应用页签及参数深链均须支持刷新。

## 保持不变

Service／ParameterBinding 的所有权模型、参数全局唯一 Key、层域作用域、共享标签目录及固定实验 `parameterKeys` 不变。标签不改实验值或流量；目录内认领不改旧实验分桶。真实 SDK、凭证、RBAC、服务端审批与多标签页并发保证不在范围内。
