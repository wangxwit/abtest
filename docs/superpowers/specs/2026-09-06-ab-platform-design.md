## 当时设计

| 范围 | 当时设计 |
| --- | --- |
| 工作台 | 总览、实验列表、搜索筛选、指标与报告演示 |
| 创建 | 三步弹窗；校验 Key、流量与参数，保存草稿 |
| 生命周期 | 本地模拟提交、审核、运行、暂停和结束 |
| 层域 | Google 域切流量、层分参数；示例重叠域 80%、非重叠域 20% |
| 实现 | React、TypeScript、Vite、Lucide、Recharts、localStorage |

视觉采用中文桌面工作台、浅灰背景、白卡、绿色主色；窄屏折叠侧栏，表格可滚动。图表为示例，新实验无虚构结果。

初版浏览器只实现本地交互，没有真实认证、统计引擎或生产 SDK。
