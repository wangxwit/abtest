# 企业实验平台 · 原型设计

用户已选择交付可运行交互原型，并附产品与架构方案。面向产品、研发、算法、数据分析与平台管理员，统一管理前端、后端、策略实验。

采用统一实验模型与可插拔执行方式。可选路径包括完全自建平台、整合外部实验服务、统一控制台对接已有执行与数据设施；当前推荐第三种架构，原型展示其控制面，不连接生产服务。

## 交互范围

- 总览：项目实验规模、参与人数、趋势、风险提醒与最近实验。
- 实验管理：搜索、按状态和类型过滤、详情、指标/配置/审计页签。
- 创建：基础信息、流量与版本、指标与审核三步；验证唯一标识与流量总和；存草稿。
- 生命周期：草稿→待审核→运行中→暂停/已结束。审核通过模拟审核者角色，所有变更记录本地活动。
- 层域管理：按 Google 2010 §4 / 图2b，100% 流量互斥切为80%重叠域和20%非重叠域。重叠域按参数分三个层；非重叠域单全参数层。展示桶区间、参数权限、全局折算和真实本地分流模拟。
- 指标中心、受众管理、实验报告、SDK 集成、团队权限提供可阅读、可筛选的演示内容。

## 视觉规范

中文桌面企业工作台。浅灰背景、白色卡片、森林绿主色、青柠色辅助图形；固定侧栏、清晰的信息层级、紧凑但有留白的数据表格。数字使用等宽数字，图标统一 Lucide。移动端侧栏折叠，表格有明确横向滚动区域。

## 实现边界

React + TypeScript + Vite，浏览器 localStorage 保存模拟数据。界面明确标记演示工作区。无服务端身份认证、真实统计推断、生产分流或实际 SDK 发布；设计文档说明生产架构。所有页面按钮应有实际效果或说明界限，不伪造接入成功。

## 验收

构建通过；浏览器核验搜索、类型/状态筛选、创建校验与保存、审核和状态流转、报告导出、刷新持久化、导航及窄屏布局；验证草稿和无数据实验不显示虚构统计结果。

## 已纳入的用户修正

用户要求遵循 Google AB 实验论文。域切分流量、层划分参数，工程类型与层域解耦。创建先选域/层，再登记该层拥有的参数；校验桶冲突/容量；暂停保留区间。已通过1,000个模拟用户验证兄弟域互斥、同层至多一次、跨层多次命中和确定性。
