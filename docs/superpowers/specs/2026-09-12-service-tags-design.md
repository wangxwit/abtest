# 应用管理与服务参数归属：历史设计

现行规范见[文档导航](../../README.md)；生产 Namespace 与权限见[专章](../../服务端技术方案/05-Namespace与权限设计.md)。

## 当时设计

- 一级入口合并为“应用管理”；应用详情有概览、参数、接入配置、运行观测、关联实验。
- 参数绑定一个应用；内置参数明确映射，旧自定义参数待认领，不根据 Key 前缀猜归属。
- 实验从固定参数集合推导涉及服务；跨应用选参仍受层范围限制。
- 服务接入按环境保存 direct／delegated；委托只指向同环境网关，禁止自委托和环。
- 保存失败保留原配置，标签与认领不改变已有实验分桶。

当时包含全局参数页、跨应用共享标签及局部 parameterRules；均属于历史设计。运行观测显示无真实数据，不提供手动“已连接”。
