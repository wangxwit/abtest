## 实施分工

1. 核心负责人：pending 状态、激活范围、登记与首次归层计划、空层与保存转换约束及自动化测试。
2. 参数界面负责人：登记移除归层步骤、待归层展示、独立归层入口与递归配置。
3. 主执行者：建层空态与首次归层整合、实验和分流限制、集成测试及浏览器验收。
4. 独立审查与文档：检查星号扩张、空层 A/A、旧数据兼容、循环依赖及保护绕过；更新当前产品文档，保留历史验证。

## 验收清单

- [x] 无预建目标层也能登记参数，保存为待归层；刷新保留定义、应用与私有标签。
- [x] 注册后默认层、非重叠星号层和递归层作用域均不扩张；显式 pending 层引用及 pending 实验参数被拒绝。
- [x] 合法重叠域能先保存空层；空层不承载实验、零参数 A/A 或子域，分流及并发统计不把空层作为可执行层。
- [x] 待归层参数能独立配置已有空层；全部受影响域完成前不能激活，缺失、越界及重复分配被拒绝。
- [x] 建层可选择待归层参数一次建层并激活；深层目标的祖先路径、其他受影响兄弟分支及后代均合法。
- [x] 保存拒绝 active → pending、清空／删除旧非空层及绕过未结束实验、子域保护的直接转移。
- [x] 旧无 pending 字段数据保持激活归属；注册、激活与建层不改变已有实验 Key、取值及分桶。
- [x] 私有标签与应用参数范围回归无变化；模块导入、全部测试、构建与浏览器核心路径通过，实际证据写入 VERIFICATION。
