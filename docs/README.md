## 文档约定

| 表达方式 | 用途 |
| --- | --- |
| Mermaid | 模块关系、数据流、状态和授权流程 |
| 树 | 资源归属与导航层级 |
| 表格 | 字段、权限、状态、差异和实现边界 |
| 短列表 | 顺序操作、约束和验收条件 |
| 段落 | 解释原因、例外和适用条件 |

同一规则只在主文档详细定义，其他文档用摘要和链接。身份／权限以服务端 05 为准，表结构以 01 为准，API 以 02 为准，分桶以 03 为准，指标以 04 为准。
