# EXP Lab · 企业 AB 实验平台

原型说明 v23 · 2026-09-16。实验分组增加适合长 JSON 的源码工作台、专注编辑、只读参数目录和组间结构差异；编辑原文继续随草稿保存。v22 的层域负责人、长期／临时、预计结束日期及详情编辑继续保留，到期只做管理提醒。全页实验草稿工作区、递归层域、应用参数管理、固定受众版本、10,000 桶自动组合及 2–20 个分组保持，组合约束维持下线。

以 Google 递归层域模型统一管理实验的中文交互原型。“应用管理”以应用／服务为入口，参数只在所属应用的“参数”页签维护，不提供全局“全部参数”页面。服务登记参数后先处于待归层状态，完成独立归层配置后才参与实验；域内的层划分已激活参数作用域，实验选择固定参数集合并配置各分组取值；参数可添加所属应用私有的多个业务标签，不同应用可使用同名但不同 ID 的标签。涉及服务及负责人从参数归属自动汇总，创建实验无需选择前端、后端或算法类型。

## 运行

需要 Node.js 22.12+（本次开发环境为 Node.js 25）。

```bash
npm install
npm run dev
```

打开 [本地原型](http://127.0.0.1:5173)。

```bash
npm run build  # TypeScript 检查与生产构建
npm test       # tests/*.test.mjs：层域、参数、服务、标签、受众、多分组与历史兼容
npm run preview
```

## 建议体验路径

1. 打开一级“应用管理”，查看应用目录，登记前端应用、后端服务、策略服务或网关 / BFF。应用／服务详情包含概览、参数、接入配置、运行观测、关联实验五个页签。
2. 在应用／服务的接入配置中分别选择开发、测试、生产环境。可直接决策，或委托同环境的网关 / BFF；保存仅影响当前环境，所有接入状态仍是待验证。
3. 进入具体应用的“参数”页签注册参数。所属服务固定为当前应用，填写唯一 Key、类型、默认值、负责人和本应用业务标签，保存为“待归层”，注册时不要求选择层；需要其他应用时先回应用目录登记。
4. 在该应用的“参数”页签搜索、按标签或层筛选，查看参数定义、逐域归属、实验引用与各分组取值，并维护当前应用参数的标签。标签的查看、创建与维护均限定当前应用；待归层参数可独立配置其在所有受影响域的唯一归属后激活；跨服务组合选参在创建实验中完成。应用目录仅在存在历史待归属服务的参数时显示认领区，两种待处理状态相互独立。
5. 创建实验，进入“实验目标／范围与流量／分组与参数／检查与提交”全页工作区，可以自由切换，未完成当前区也可先编辑其他内容。从层进入会带入域和层；从已有实验复制会保留原参数值及固定受众资格，并生成新的分组 ID，不复用旧桶。
6. 配置 2–20 个实验分组，其中一个对照组。支持新增、复制、删除、设为对照及显式均分流量；各组使用相同参数 Key 集合。在源码工作台中用行号、折叠、搜索／替换和只读参数目录定位长 JSON，也可进入“专注编辑”，通过“分组差异”与另一个实际分组比较。组合约束已下线，类型、归层和完整性仍自动校验。涉及服务自动显示；标签变化不会自动增删已保存的实验参数。
7. 草稿自动保存，也可手动保存；刷新或从实验列表的“编辑中的草稿”继续。最后检查可定位具体配置区、分组和参数 Key。通过最新校验后提交为“待审核”并预留流量，启动仍需独立演示审核操作；新实验不产生虚构样本和收益。
8. 打开“层域管理 → 层域配置”，展开默认域 → 默认层 → 常规重叠域 → 展示参数层 → 界面探索子域 → 内容交互子层 → 内容深度探索域 → 孙层。查看逐级流量折算与参数范围；域或层上的“验证分流”进入验证页并带入关注节点。
9. 选择有激活参数的层新建子域，填写名称、模式、流量与可选受众，并设置管理信息：负责人默认演示当前用户“陈思远”，使用期限默认长期，改为临时时填写预计结束日期。自动生成一个“初始参数层”承接全部继承参数并复制本次管理信息，无需填写 A/B 两层名称或划分参数。单参数父层也可创建重叠域；空父层仍被阻止，非重叠祖先限制继续生效。之后在合法重叠域内“新建层”按业务拆分，也可先保存空层或选择待归层参数首次归层；新层同样可填写管理信息。原非空来源层须保留参数，未结束实验和子域依赖仍受保护。非重叠域保持一个完整参数层。
10. 在“受众管理”分别维护画像属性和受众版本。属性目录记录 Key、类型、取值与统计口径，无需绑定来源应用，独立于实验参数；受众用 AND／OR 条件组圈选用户。域／实验旁可快捷新建并选中固定版本；实际资格为全部祖先域条件 AND 当前受众。用同一 user_id 的固定快照模拟，自定义属性也随首次画像保存，缺字段不能给旧用户补填。
11. 受众目录允许人群重叠；只有完整有效条件可证明互斥时，才允许同父层复用相交桶。OR 必须检查全部分支组合，未知不能证明互斥；未匹配不换桶补量。人工填写基数与桶内合格率做场景估算，受众规模及真实曝光显示未接入；查看实验详情、指标和 CSV，刷新验证配置。
12. 在“分流验证”手动输入 user_id 与画像，执行从默认域开始的完整模拟，查看全部并行路径。关注节点的“已到达”不代表命中实验；未到达时查看首个祖先阻断、桶外、准入记录或空层跳过原因，可返回对应配置。两个页签间切换和从结果返回层域配置会保留输入及结果；输入或配置变化后须重新模拟。

分流验证路由为 `#traffic/validation`，关注域／层为 `#traffic/validation/domain/<id>`／`#traffic/validation/layer/<id>`，ID 安全编码。关注不改变起点、桶位、画像或实验筛选，也不隐藏并行分支。输入与结果仅在层域页常驻内存中保留，不承诺刷新或离开一级导航后恢复。固定资格画像仍使用已有 localStorage；刷新后再次输入同一 user_id 可读取只读快照，但必须手动生成新的模拟结果。

实验草稿路由为 `#experiments/new`，按层入口为 `#experiments/new?layer=<id>`，复制入口为 `#experiments/new?copy=<experimentId>`；首次保存后使用 `#experiments/drafts/<draftId>`。草稿保存表单、当前配置区和选中的分组，不预占流量。复制旧实验时，已知受众名称映射到原内置固定版本；未知旧条件保持未解析状态并阻止提交，须显式重新选择，不能自动扩大人群。

版本冲突会暂停自动保存并保留当前页内容，可另存当前草稿、导出或加载最新版本。读取失败、坏版本和存储额度不足均明确报错，不用空白内容覆盖原稿。已提交草稿保留对应实验标记，从编辑列表移除；再次提交或打开时按来源草稿身份定位既有实验。

按标签选参须先选应用，仅显示其私有标签，多标签任一匹配；切换应用清除标签筛选并保留跨应用累计的已选参数。待归层、越层、待归属服务或已加入的参数不可加入；批量加入保留各组已有值，并为新增项填入登记默认值。

域继承范围、层关联参数、新建层和新建子域共用应用参数浏览方式：按真实服务归属分组，可搜索 Key、登记名称和应用名称；选定应用后只显示其私有标签，多标签任一匹配。新建层的跨应用已选 Key 保留，不把层绑定到单一服务，候选仍含待归层及允许转移的参数。创建子域的继承参数仅供只读查看，应用／标签筛选不改变初始层承接的完整父范围。编辑中的参数浏览不跳离弹窗，避免丢失草稿。v16 的创建时 A/B 双层划分已由 v18 的“先建域，再按业务拆层”取代。

创建受众时自动检查条件自身、祖先交集与已登记受众的关系；域／实验内同时检查当前层的可用桶段，提交前再次检查。普通人群重叠仅提示，条件矛盾或当前流量所需桶数超过可用总量时阻止内联保存。

受众详情的“查看引用实验”进入实验列表，筛选直接引用或通过祖先域继承该固定版本的实验。画像属性详情按直接使用此属性的受众版本提供实验列表入口，同一实验可出现在多个版本的引用集合中。列表每次选择一个受众版本，可与搜索、状态、涉及服务及“只看我负责的”组合；这是配置引用关系筛选，不表示用户已命中或曝光。外部受众入口清除残留的其他筛选，列表内主动切换受众则保留其他筛选；切换重置页码，清除与列表刷新同步 URL，详情的返回按钮保留来源列表受众。

实验筛选路由：`#experiments?audience=<id>`，不带受众参数为完整实验列表；未知或无效受众参数显示可清除的空态。v14 实验详情条件定位只兼容旧链接，新的引用入口不再跳到聚焦详情。域引用仍进入既有域条件页面，本轮不新增域列表。

受众路由：`#audiences`／`#audiences/<id>`；画像属性 `#audiences/attributes/<key?>`，支持刷新与未知标识反馈。

应用规范路由：应用目录 `#applications`；可刷新页签 `#applications/services/<id>/<tab?>`；本应用参数 `#applications/services/<id>/parameters/<key?>`。旧全局参数列表返回应用目录；旧参数 Key 深链定位到实际所属应用，未归属或未知 Key 在目录内反馈，不退回展示另一个参数。

## 层域管理信息

域和层详情的“管理信息”支持直接编辑、保存和取消。负责人必填，保存时去除首尾空格，最多 40 个字符；使用期限为长期或临时，长期不保存日期，临时必须填写真实有效的 `YYYY-MM-DD` 日期。允许填写过去日期，按浏览器本地日期显示“今日到期”或“已超期”，到期不会停用资源、结束实验或回收桶。

旧节点没有管理信息时仍显示“未设置”，不自动补造负责人。子域创建时，初始参数层复制一次该域的负责人、期限和日期；之后两者可独立编辑。管理信息与原拓扑一同保存在 `exp-lab-topology-v1`。保存前发现其他页面已修改拓扑时拒绝过期写入，并保留当前表单输入；这不是跨标签页原子事务，也不提供跨设备同步。

## 长 JSON 参数编辑

“分组与参数”首次打开时按需加载 CodeMirror 6 源码编辑器；专注模式扩大至当前视口，并提供组间切换。每个分组在当前编辑器会话内独立保留光标、折叠、滚动位置和撤销历史；刷新或重新打开编辑器后不恢复这些临时状态。原始 JSON 文本仍按组写入既有草稿，包含未完成或错误文本，保存失败与冲突沿用草稿恢复机制。

参数目录只读浏览对象、数组及内部路径，可搜索字段、路径、值和登记名称，也可按实际所属应用及其私有标签筛选；筛选不裁剪源码、不修改 Key 集合或参数归属。点击目录或 JSON 问题定位到源码。校验要求顶层对象、严格 JSON、无重复属性、有限数字及最多 32 层；重复属性包括转义后同名字段。目录最多展示 5,000 个节点，完整内容仍参与校验和差异比较。格式化仅处理通过校验的内容；导出保存当前组的完整源码原文，错误文本也不会被悄悄替换。

“分组差异”选择另一个实际分组作为比较对象，只读展示新增、删除和修改路径及前后值；忽略缩进与对象字段顺序，数组整体比较，重排也记为修改。任一组 JSON 无效时停止比较。此处没有补丁应用、自动合并或组间继承；固定基线／覆盖、参数表格、可编辑 JSON 树、字段 schema 和 CSV 导入仍按[后续方案](./docs/多分组与批量参数配置方案.md)建设。

## 实现边界

这是可运行的前端交互原型。目录、注册、分流模拟与实验配置执行本地校验；图表和已有实验结果是演示数据。没有真实后端、RBAC、服务端审批、生产 SDK、凭证、部署校验、曝光采集或统计引擎。服务接入模式保存的是设计配置，运行观测显示无数据，不能手动将服务标记为已连接。

服务、标签、画像属性、受众版本、参数定义、递归层归属及层域管理信息保存在 `exp-lab-topology-v1`；正式实验及状态保存在 `exp-lab-experiments-v3`，旧版键保留。v21 编辑草稿按 `exp-lab-experiment-draft-v1:<draftId>` 逐项独立保存，带 revision 乐观检查；这不构成跨标签页原子事务、多人协作同步或跨设备共享，正式实验写入与草稿提交标记也不是一个服务端事务。内置 13 个参数映射到示例服务；旧自定义参数保持原 Key 与取值并显示待归属，通过应用目录内的认领区明确服务，不根据前缀猜服务。新实验选参要求服务已明确；旧实验继续兼容。

旧共享标签按实际使用参数的所属应用拆成私有副本，保留名称、颜色与关联；未归属或未引用的旧标签保留隐藏归档。未归属参数认领后在目标应用恢复标签。无效目录或迁移保存失败时保留原数据并阻止保存，不静默覆盖。

参数 Key 当前仍在整个工作空间唯一。未启用服务内同名 Key、自动改名或服务迁移；已明确的所属服务不可直接改写。参数定义支持 string、number、boolean、object、array 与有限 JSON 校验；范围约束、对象字段 schema、定义编辑／删除及版本发布尚未实现。

默认值只在编写新实验时补入各分组初值，保留已填写值。没有锁定默认值版本、编译完整运行快照或合并所有目录默认值；模拟器仅返回命中实验的显式覆盖。标签是应用内分类工具，参数不能绑定其他应用的标签；保存实验时使用固定 `parameterKeys`。组合约束功能在 v20 下线，旧 `parameterRules` 及历史联动规则仅保留存储兼容，不再参与创建、审核或分流校验。

画像属性目录与实验参数目录独立，属性类型及语义不能静默改写；登记不代表已上报真实画像。受众 AND／OR 条件最多 3 层分组、30 条规则，以不可变版本保存，域与实验引用后与祖先域条件相交，旧平铺规则仍按 AND 执行。同桶复用只接受同 user_id 固定资格快照下所有分支组合的互斥证明；展开超过 64 个组合时仍可按完整树求值，但不能据此放行桶复用。未知也不能放行冲突。受众规模不使用虚构数据；人工估算明确基数和合格率假设，真实画像、快照服务、分配／曝光与生效数据均未接入。

旧 `type` 字段仅兼容历史结构，界面不再以实验端类型作为主分类。旧 `coordination` 执行端绑定继续按历史契约校验；新建实验使用服务推导与多个分组配置，不再填写多端实现矩阵。

## Google 层域模型

依据 Tang 等人 2010 年 KDD 论文 §4：域切分流量，层划分参数。兄弟域互斥；同一域内普通层的参数不重复，各层独立分流；同一层只能选择一个直接实验或子域，再递归进入子层。非重叠分支至多命中一个实验，但不会自动隔离祖先域的其他并行参数层。服务归属和标签不改变这些规则。

初始 80%/20% 根比例、user_id、10,000 个固定桶、多段分配与 FNV 派生 hash 是本平台演示配置，非论文规定。域深度最多 16 级；共享对照、发布层执行、生产哈希与跨语言一致性协议未实现。新建域按低桶号组合当前可用桶，仅在同用户固定资格条件可证明互斥时允许复用已有区间；运行中迁移、域份额编辑和节点删除仍需单独设计。

旧平铺配置升级只在连续空闲桶中加入示例子域，空间不足则跳过；已保存域树优先保留。新建层可先留空，也可对待归层参数完成首次分配；转移已激活参数仅允许同域未被未结束实验使用、没有子域继承的参数，来源层至少保留一个参数。注册不扩张任何层的作用域，星号也不包含待归层参数。首次归层完成全部受影响域分配后一次激活，不能把已激活参数退回待归层来绕过保护。旧无待归层字段的数据保持原有激活归属。注册、归层、标签维护和服务配置不改变已有实验分桶。
